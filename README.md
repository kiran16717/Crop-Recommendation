# 🌾 Crop Recommendation System

This project uses Machine Learning to recommend the best crop based on soil and environmental conditions.

## 📌 Features
- Input: Nitrogen, Phosphorus, Potassium
- Temperature
- Humidity
- pH level
- Rainfall
- Output: Recommended Crop

## 🛠 Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## 🚀 Model Used
Random Forest Classifier

## 📊 Accuracy
~95% (depending on dataset split)
